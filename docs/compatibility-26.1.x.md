# Проверка общего JAR 26.1.x

Дата: 02.11.2026. Загрузчик Fabric 0.20.1, Cloth Config 26.1.154,
Fabric API 0.155.3+26.1.2 (его метаданные допускают всю ветку 26.1).

- Minecraft 26.1: общий JAR 1.0.1+fabric.26.1.x, запуск, новый мир,
  анимация в инвентаре выживания и Ctrl+O проверены через computer-use.
- Minecraft 26.1.1: тот же JAR, запуск, новый мир, анимация в творческом
  инвентаре и Ctrl+O проверены через computer-use.
- Minecraft 26.1.2: ранее проверены анимация, настройки, карточки, возврат
  из выбора с сохранением ввода. Все 40 class-файлов нового общего JAR
  побайтно совпадают с проверенной сборкой для 26.1.2.

Сборка против базовой 26.1 проходит без изменений исходного Java-кода.
Диапазон Minecraft расширен с ~26.1.2 до >=26.1 <26.2.
Проверка охватывает выпущенные 26.1, 26.1.1 и 26.1.2;
будущие обновления 26.1.x потребуют повторной проверки.
