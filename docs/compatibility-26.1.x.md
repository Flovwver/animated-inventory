# Проверка общего JAR 26.1.x

Дата: 02.11.2026. Cloth Config 26.1.154 для NeoForge.

- Компиляция против NeoForge 26.1.0.19-beta (Minecraft 26.1) проходит.
- Компиляция против NeoForge 26.1.1.15-beta (Minecraft 26.1.1) проходит.
- Все class-файлы обеих сборок побайтно совпадают с ранее проверенным
  JAR для NeoForge 26.1.2.125. Java-код менять не потребовалось.
- NeoForge 26.1: запуск, загрузка копии мира 26.1, анимация в инвентаре
  выживания и открытие настроек Ctrl+O проверены через computer-use.
- NeoForge 26.1.1: запуск, загрузка копии мира 26.1, анимация в инвентаре
  выживания и открытие настроек Ctrl+O проверены через computer-use.
- NeoForge 26.1.2: ранее проверены мир, анимация, Ctrl+O, выборщик и общий
  откат изменений TOML, позиций и параметров кадров с проверкой SHA-256.

Minecraft ограничен диапазоном [26.1,26.2), NeoForge — [26.1.0.19-beta,26.2).
Используйте последнюю сборку NeoForge для своей версии Minecraft.
Будущие обновления 26.1.x потребуют повторной проверки.
Тестовые каталоги run-<версия NeoForge> не включаются в коммиты.
