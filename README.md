# Inventory GIF — Fabric 26.1.x

Клиентский мод для **Minecraft 26.1.x**, **Fabric**, **Java 25**.
Показывает GIF и PNG поверх инвентарей и контейнеров.

## Установка

Сборка: `.\gradlew.bat build`.
Мод: `build/libs/inventorygif-1.0.1+fabric.26.1.x.jar`.
Поместите его в `mods` вместе с Fabric API для 26.1.x и **Cloth Config 26.1.154 для Fabric**.
Версии для разных загрузчиков не взаимозаменяемы. Серверу мод не нужен.

## Управление и настройки

- Ctrl+O в инвентаре открывает настройки.
- Ctrl+L включает блокировку картинок текущего экрана.
- Левой кнопкой можно перемещать картинку, за угол — менять размер.
- Кнопка папки открывает `inventorygif/animations/` текущей игры.
- Добавление открывает библиотеку; выход без выбора ничего не добавляет.
- Каждая картинка имеет карточку с миниатюрой, координатами и масштабом.
- Удаление привязки не удаляет исходный файл.

Общие параметры, привязки и параметры кадров редактируются в черновике.
«Сохранить и выйти» применяет изменения, «Отмена» откатывает их.
Привязки поддерживают наследование от родительского экрана.

## Файлы

- `config/inventorygif-client.toml` — общие параметры.
- `config/inventorygif-positions.json` — привязки и дерево экранов.
- `inventorygif/animations/` — GIF, PNG и JSON с параметрами кадров.

Существующие файлы настроек сохраняют свой формат.
Cloth Config — официальная зависимость, сохранённая в `libs`;
в JAR мода она не включается и устанавливается отдельно.

## Совместимость 26.1.x

Один JAR предназначен для Minecraft 26.1, 26.1.1 и 26.1.2.
Загрузчики остаются раздельными: Fabric-файл используется с Fabric,
NeoForge-файл — с NeoForge. Cloth Config 26.1.154 устанавливается отдельно
в варианте для выбранного загрузчика. Базовая версия компиляции — 26.1.
